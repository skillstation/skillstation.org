Determine the value of the following limit:
$$\lim_{x\to 0}\frac{x\sin x}{1-\cos x}$$
A. 0
B. 1
C. 2
D. 4
Solution
Using standard limits:
$$\sin x \sim x,\quad 1-\cos x\sim\frac{x^2}{2}$$
Therefore,
$$\lim_{x\to0}\frac{x^2}{x^2/2}=2$$
Correct answer: C. 2

[Maximum mark: 6]
Consider the function:
$$f(x)=x^2e^x$$
Find the derivative of the function using the product rule.
Solution
Using the product rule:
$$\frac{d}{dx}(uv)=u'v+uv'$$
Taking: $$u=x^2,\quad v=e^x$$ Therefore: $$f'(x)=2xe^x+x^2e^x$$ $$\boxed{f'(x)=e^x(x^2+2x)}$$
